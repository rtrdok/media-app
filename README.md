# Media App

Windows-приложение: скачивание видео и музыки, библиотека, плейлисты, плеер, Shazam и поиск аниме по кадру.

---

## 🇷🇺 Русский

### Возможности
- Скачивание с YouTube, TikTok, Instagram, Coub, VK, RuTube, X, SoundCloud, Яндекс Музыка
- Библиотека, плейлисты, избранное, поиск, перемешивание и повтор
- Встроенный плеер: очередь, тексты песен, мини-плеер поверх окон, горячие клавиши
- Прокси и cookies — если сервисы недоступны в вашем регионе
- Автообновление с GitHub (Настройки → Проверить / Скачать и обновить)
- Настройки и история сохраняются и **не сбрасываются** при обновлении

### Установка
1. Открой [последний релиз](https://github.com/rtrdok/media-app/releases/latest)
2. Скачай **MediaApp-Installer.exe** (рекомендуется) или **MediaApp.zip**
3. Установщик ставит программу в `%LOCALAPPDATA%\MediaApp` и создаёт ярлык  
   Либо распакуй zip и запусти `MediaApp.exe`

### Обновление
В приложении: **Настройки → Проверить обновления**.  
Если есть новая версия — **Скачать и обновить**. В каждом релизе коротко написано, что изменилось.

### Горячие клавиши
| Клавиша | Действие |
|--------|----------|
| Пробел | Play / Pause |
| Ctrl + ← / → | Предыдущий / следующий трек |
| ↑ / ↓ | Громкость |
| L | Текст песни |
| Q | Очередь |

## 🇬🇧 English

### Features
- Download from YouTube, TikTok, Instagram, Coub, VK, RuTube, X, SoundCloud, Yandex Music
- Library, playlists, favorites, search, shuffle and repeat
- Built-in player: queue, lyrics, mini-player always on top, keyboard shortcuts
- Proxy and cookies for restricted regions
- Auto-update from GitHub (Settings → Check / Download & update)
- Settings and history **survive** updates

### Install
1. Open the [latest release](https://github.com/rtrdok/media-app/releases/latest)
2. Download **MediaApp-Installer.exe** (recommended) or **MediaApp.zip**
3. The installer puts the app in `%LOCALAPPDATA%\MediaApp` and adds a shortcut  
   Or unzip and run `MediaApp.exe`

### Updates
In the app: **Settings → Check for updates**, then **Download & update** if available.  
Each release includes a short changelog.

### Shortcuts
| Key | Action |
|-----|--------|
| Space | Play / Pause |
| Ctrl + ← / → | Previous / next track |
| ↑ / ↓ | Volume |
| L | Lyrics |
| Q | Queue |
